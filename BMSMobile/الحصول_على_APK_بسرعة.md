# كيف تحصل على ملف APK خلال دقائق (بدون تثبيت أي شيء)

أسهل طريقة = البناء السحابي عبر **GitHub Actions**. الملف اللازم مضمّن بالفعل داخل المشروع:
`.github/workflows/build-apk.yml`

## الخطوات

1. أنشئ حسابًا مجانيًا على [github.com](https://github.com) إن لم يكن لديك.
2. أنشئ مستودعًا جديدًا (New repository) — اجعله Private إن أردت.
3. ارفع **كل محتويات مجلد المشروع** (بما فيها مجلد `.github`) إلى المستودع.
   - عبر المتصفح: زر **Add file → Upload files** ثم اسحب الملفات.
   - أو عبر git:
     ```bash
     git init && git add . && git commit -m "BMS Mobile"
     git branch -M main
     git remote add origin https://github.com/اسمك/اسم-المستودع.git
     git push -u origin main
     ```
4. افتح تبويب **Actions** في المستودع — سيبدأ البناء تلقائياً (أو اضغط **Run workflow**).
5. بعد انتهاء البناء (​~بضع دقائق)، ادخل على المهمة ثم نزّل ملف **BMS-Mobile-APK** من قسم **Artifacts**.

ذلك الملف هو `app-debug.apk` جاهز للتثبيت مباشرة على الجوال.

---

### لماذا لا يُنتَج الـ APK هنا مباشرة؟
حتى «مجرد تغليف الصفحات» داخل APK يتطلب تحويل ملف الـ Manifest والموارد إلى صيcة ثنائية (aapt2)،
وتحويل الكود إلى dex (d8)، ثم توقيع الحزمة (apksigner) — وهذه أدوات Android SDK غير متوفرة في بيئة العمل هنا،
ولا يمكن تنزيلها (لا يوجد إنترنت). لذلك البناء السحابي أعلاه هو أسرع حل عملي.
